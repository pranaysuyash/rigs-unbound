# Rigs Unbound Operations

This is the navigation page for deployment, release, and other operational
surfaces. It is not the procedure itself; it points at the runbook and the
ordered evidence surfaces that should be read before changing release state.

## Start here

- [Sites update and deployment runbook](SITES_UPDATE_AND_DEPLOY_RUNBOOK.md)

## Suggested order

1. Read the comms package first if the change affects the launch or public
   announcement package.
2. Read the reviews index next if the change affects evidence, approval, or
   deployment acceptance.
3. Read the execution tracker and worklog before changing release state.
4. Use the Sites update and deployment runbook for the actual operational
   procedure.

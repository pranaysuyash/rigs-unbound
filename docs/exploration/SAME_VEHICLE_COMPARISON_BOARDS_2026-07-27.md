# Same Vehicle Comparison Boards

- Status: **living exploration doc**
- Date: 2026-07-27
- Purpose: record paired mode comparisons for the same tractor identity so later image, model, and gameplay experiments can reuse the same machine under different contracts

## Why these boards exist

The mode matrix is useful, but comparison boards make the tradeoffs visual.
They answer questions like:

- what changes when the same tractor becomes a race machine?
- what changes when the same tractor becomes a scavenger shelter?
- what changes when the same tractor becomes a civic oddity or a mythic object?

The boards are not final art direction. They are evidence for identity
continuity under genre pressure.

## Board ledger

### 1. Farming versus racing

File:

- [farming-vs-racing-board-2026-07-27.png](assets/same-vehicle-mode-atlas-2026-07-27/farming-vs-racing-board-2026-07-27.png)

What it proves:

- the same machine can feel like work and competition without losing its cab,
  wheelbase, or repair grammar;
- racing can be a route/weight/traction story rather than a completely different
  vehicle archetype;
- the difference is mostly in camera, terrain contract, dust, and tuning.

### 2. Survival versus construction

File:

- [survival-vs-construction-board-2026-07-27.png](assets/same-vehicle-mode-atlas-2026-07-27/survival-vs-construction-board-2026-07-27.png)

What it proves:

- the same tractor can serve as a shelter in one panel and a site tool in the
  other;
- scavenged cargo and patched armor still read as the same machine;
- boom arms, drill masts, stabilizers, and salvage clamps can be added without
  erasing the core identity.

### 3. Urban versus absurd

File:

- [urban-vs-absurd-board-2026-07-27.png](assets/same-vehicle-mode-atlas-2026-07-27/urban-vs-absurd-board-2026-07-27.png)

What it proves:

- the same tractor can sit in a city street as a strange but plausible service
  machine;
- absurd mode can stay legible if the original silhouette and repair history are
  preserved;
- mythic escalation is useful only if the machine remains recognizable.

## Working conclusions

- mode changes should be felt first through lighting, camera, and loadout;
- if a mode requires a new machine silhouette, that is probably a new family;
- the tractor can survive genre pressure as long as the cab, wheel family, and
  repair history remain stable;
- absurdity is allowed when it clarifies identity rather than replacing it.

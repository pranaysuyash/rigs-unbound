- `cargo-fuselage`: High-capacity steel/composite cargo bay fuselage hull

- `quad-tilt-rotors`: 4 pivoting wing nacelle tilt-rotor engines with propellers
- `rear-loading-ramp`: Rear hydraulic clam-shell cargo loading ramp
- `multi-wheel-landing-gear`: Heavy 6-wheel retractable landing gear assembly
